# 月夜の人狼 / Moonlit Werewolf

ブラウザだけで遊べる人狼ゲーム。オーナーが部屋を作り、参加者は画面のQRを読み取って参加します。

- 遊ぶ: https://jerry-hijiri.github.io/jinro/
- 言語: 日本語 / English / 한국어 / 中文（端末ごとに切替）
- 役職: 村人・人狼・占い師・霊媒師・騎士・共有者・狂人・妖狐（人数に応じたおすすめ構成と有利度の目安つき）
- 進行: 開幕演出 → 役職確認 → 夜（初日の襲撃なし）→ 朝 → 議論（タイマー）→ 投票（決選投票・くじ）→ 処刑演出 → 勝敗
- BGM・効果音は Web Audio でその場で合成（音源ファイルなし）

## しくみ
- サーバーなし。オーナーの端末がゲームの進行役で、公開MQTTブローカー（WebSocket）を中継に使う
- 役職・占い結果などの秘密は端末ごとに ECDH + AES-GCM で暗号化して届ける
- オーナーの画面を閉じるとゲームが止まる（開き直せば続きから）
- ローカル確認: `python3 -m http.server` → `http://localhost:8000/?t=bc`（同じブラウザのタブ同士で通信するテストモード）
